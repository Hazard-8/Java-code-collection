# ☕ Java Code Collection

A structured collection of Java programs documenting my learning journey from basic syntax to advanced concepts.
This repository includes hands-on practice programs and mini-projects built while learning Java step by step.

## 📌 About This Repository

This repository covers a complete range of Java topics, starting from Hello World to advanced concepts like
Object-Oriented Programming,Collections, File Handling, and Multithreading. 

It is based on a structured learning path and includes both:
* 📖 **Concept-based programs**
* ⭐ **Mini-projects for practical understanding**

## 📚 Topics Covered

**🔹 Basics**
* Introduction to Java, Variables & Data Types, User Input
* Arithmetic Operations, Math Class, `printf`

**🔹 Control Statements**
* If Statements, Nested If, Ternary Operator
* Switch Statements, Logical Operators

**🔹 Loops**
* While Loop, For Loop, Nested Loops
* Break & Continue

**🔹 Methods**
* Methods & Method Overloading
* Variable Scope, Varargs

**🔹 Arrays**
* 1D & 2D Arrays
* Searching Arrays, User Input in Arrays

**🔹 Object-Oriented Programming (OOP)**
* Classes & Objects, Constructors
* Inheritance, Method Overriding, Polymorphism
* Abstraction, Interfaces
* Getters & Setters, Aggregation & Composition

**🔹 Collections & File Handling**
* ArrayList, HashMap
* Writing Files, Reading Files

**🔹 Advanced Concepts**
* Exception Handling, Wrapper Classes, Generics, Enums
* Date & Time, Anonymous Classes, TimerTask
* Threading & Multithreading
